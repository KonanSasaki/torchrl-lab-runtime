# TorchRL Lab learning runtime

A temporary CPU Python environment for the public, non-commercial TorchRL Lab learning exercises.

The learning interface runs at https://torchrl-learning-lab.naistfreib.chatgpt.site/ .
Each learner starts their own Binder session from the site's Run button. There is no shared public execution API. Answers and learning progress stay in the learner's browser; submitted code is executed in their temporary session using the actual PyTorch, TensorDict and TorchRL packages.

This repository contains only the published exercise fixtures, their runner, and Binder configuration. It contains no personal answers, credentials or research data.

Binder is community supported: initial startup can take several minutes, sessions may be culled after inactivity, and no persistent storage or availability is guaranteed. This environment is for small CPU programming exercises, not Isaac Lab simulation or long training jobs.
